% WHAT A \valign PUTS BETWEEN THE COLUMNS ONE ENTRY SPANS.
%
% This is trip's line 337 cut down to its own file. That line says
%
%   A&\omit\valign to -5pt{#&#\cr A\char`}\span\cr{ }\span\cr}\cr
%
% -- a \valign set to a NEGATIVE height whose every row ends in \span, so
% every row covers both of the columns and no row ever starts in the second.
% What trip's second pass draws of it, twice over:
%
%   ref:    ....\glue(\tabskip) 0.0
%           ....\vbox(8.0+0.0)x0.0
%   hstex:  ....\glue(\tabskip) 4.49998 plus 7227.0
%           ....\vbox(3.50002+0.0)x0.0
%
% and 8.0 - 4.49998 = 3.50002 exactly, so the two are not disagreeing about
% any length: they are splitting one length between the glue and the box in
% two different ways. [A] below is the whole of that in six lines.
%
% WHAT THE REFERENCE DOES, measured over three \tabskip values -- 4.5pt,
% 10pt and nothing at all. The glue in front of the covered column is 0.0
% every time, and the column keeps the entry's whole extent, 6.83331, every
% time. HSTeX draws the \tabskip and gives the column what is left, which is
% 2.33331 at 4.5pt and -3.16669 at 10pt. Where it comes from is the
% measuring loop in finish_alignment: a span's excess goes to the LAST
% column it covers, and what it already covers is counted as the columns
% plus THE TABSKIPS BETWEEN THEM.
%
% THE RULE IS NOT `A \valign HAS NO GLUE INSIDE A SPAN'. That was tried
% first -- not counting the tabskip while measuring, and drawing zero in its
% place -- and [B] refutes it: one row that spans and one that does not,
% where the reference draws the \tabskip in full, 10.0, in the spanning row
% as well. Recorded because it is the obvious rule and it is wrong.
%
% THE RULE, WHICH [C] AND [D] SETTLE: NOTHING STANDS IN FRONT OF A COLUMN NO
% ROW BEGINS IN. In [A] every row spans both columns, so no row begins in the
% second, and the glue in front of it is zero. In [B] the second row begins
% in both, so both glues are drawn. [C] separates the two halves of that:
% three columns, every row written `A\span&C', so no row begins in column one
% and every row begins in column two -- and the reference draws 0.0 in front
% of column one and the \tabskip in full in front of column two.
%
% AND IT IS NOT A \valign RULE. [D] is [C] written as an \halign and the
% reference does the same thing, which is why the five \halign cases of
% what-an-entry-that-spans-is-set-to.tex never caught it: every one of them
% has a row that begins in every column, so no column is ever only spanned
% into. HSTeX drew the \tabskip there and gave the column what was left,
% which for [D] came to a box of width -2.49998.
%
% Settled in the column's own record rather than where the glue is drawn,
% because three places read it: the measuring loop counts what a span
% already covers as the columns plus the glue between them, each row draws
% it, and the row the preamble is packed as draws it again -- which is why
% [A] drew `10.0 0.0 10.0' in the reference against `10.0 10.0 10.0' here.
% One rule in the record gives all three.
\catcode`\{=1 \catcode`\}=2 \catcode`\#=6 \catcode`\&=4
\tracingonline=1 \showboxbreadth=99 \showboxdepth=99
\font\tenrm=cmr10 \tenrm
\message{[A every row spans, which is trip line 337]}
\tabskip=4.5pt plus 7227pt
\setbox0=\hbox{\valign to -5pt{#&#\cr \hbox{A}\span\cr \hbox{B}\span\cr}}
\showbox0
\message{[A' the same with a plain tabskip, and with none]}
\tabskip=10pt
\setbox0=\hbox{\valign to -5pt{#&#\cr \hbox{A}\span\cr \hbox{B}\span\cr}}
\showbox0
\tabskip=0pt
\setbox0=\hbox{\valign to -5pt{#&#\cr \hbox{A}\span\cr \hbox{B}\span\cr}}
\showbox0
\message{[A'' three columns, every row spanning all of them]}
\tabskip=6pt
\setbox0=\hbox{\valign to -5pt{#&#&#\cr \hbox{A}\span\span\cr \hbox{B}\span\span\cr}}
\showbox0
\message{[B one row spans and one does not: the glue is drawn in full]}
\tabskip=10pt
\setbox0=\hbox{\valign to -5pt{#&#\cr \hbox{A}\span\cr \hbox{B}&\hbox{C}\cr}}
\showbox0
\message{[C nothing begins in column one; something does begin in column two]}
\setbox0=\hbox{\valign to -5pt{#&#&#\cr \hbox{A}\span&\hbox{C}\cr
  \hbox{B}\span&\hbox{D}\cr}}
\showbox0
\message{[D the same as an \halign, which does it too]}
\setbox0=\vbox{\halign{#&#&#\cr \hbox{A}\span&\hbox{C}\cr
  \hbox{B}\span&\hbox{D}\cr}}
\showbox0
\message{[done]}
\end
