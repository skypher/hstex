% WHAT A DISPLAY'S EQUATION HOLDS FOR THE VERTICAL LIST MOVES OUT OF IT.
%
% A \vadjust, an \insert or a \mark written inside $$...$$ does not stay
% in the box the equation is set as: it moves out onto the vertical list,
% landing right behind the display's line and in front of the
% \postdisplaypenalty. It is the same rule an \hbox obeys when it is put
% on a vertical list, and HSTeX had it for the \hbox and not for the
% display.
%
% \showbox of the enclosing \vbox says so directly:
%
%   .\hbox(4.30554+0.0)x5.71527, shifted 47.14236    the display's line
%   .\penalty 7                                      what the \vadjust held
%   .\penalty 0                                      \postdisplaypenalty
%
% It goes behind the WHOLE display: a number too wide to stand beside the
% equation is set on a line of its own below it, and what moves out comes
% after that line, not between the two.
%
% and so does \tracingpages, which weighs the penalty as a place the page
% could break. That is what this probe reads, because it can be compared
% without showing the box.
%
% trip line 262 writes \vadjust{\penalty7} inside the display that runs
% from line 261 to line 285.
