% HOW A METRIC IS SCALED.
%
% A metric file holds each length as a FIX WORD -- four bytes, twenty of
% them fractional -- and the reference scales it by the size the font is
% used at BYTE BY BYTE, dividing between them, each division throwing away
% what it cannot keep:
%
%   sw = ((((d*z)/256 + c*z)/256) + b*z)/beta,  less alpha where a is 255
%
% That is not the product divided by 2^20. The two agree wherever the size
% is a power of two and part company everywhere else -- `scaled 3000' is
% enough to tell them apart, and trip's own
% `at 2047.999992370605468749999pt' tells them apart by a good deal more.
%
% The SLANT, parameter one, is a pure number and is not scaled by the size
% at all: the reference reads it as the fix word divided by sixteen, and
% for a negative one that division rounds DOWNWARD.
%
% This engine multiplied and shifted. trip loads trip.tfm at five sizes,
% one of them 2047.999992370605468749999pt; every box built in that font
% was out by a hundredth of a point or so, and everything the page was
% measured against with it.
\catcode`\{=1 \catcode`\}=2
