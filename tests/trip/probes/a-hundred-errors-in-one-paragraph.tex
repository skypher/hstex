% What the hundred-error limit counts, and what it does when it is reached.
%
% Measured against pdftex:
%
%   * The count is PER PARAGRAPH. A hundred and twenty faults spread over
%     real paragraphs are all reported and draw no message at all; four
%     paragraphs of fifty faults each report all two hundred.
%   * A hundred faults inside ONE paragraph print
%
%         (That makes 100 errors; please try again.)
%
%     once -- not once per fault after the hundredth -- and the run gives
%     up there. Nothing after it is read or reported.
%   * Ninety-nine in one paragraph draw no message. The limit is reached
%     at the hundredth, not passed at the hundred-and-first.
%   * `\undefA' alone in vertical mode never begins a paragraph, so the
%     count is not forgiven between such lines.
%
% This engine reported the message on every fault past the hundredth and
% then carried on regardless, so a long enough run said it a dozen times
% and finished anyway. trip's second pass draws 182 faults and says it
% never, because its paragraphs keep forgiving what went wrong inside
% them.
%
% Run with 120 of these in one paragraph and the reference stops at 100.
X
\undefA \undefA \undefA
